# PixGram Social Media UI

## 🚀 Overview
A frontend web project built using **HTML** and **CSS** that showcases a modern, responsive social media home page interface inspired by popular platforms. The project focuses on layout structuring, visual consistency, and real-world UI design practices.

---

## 🔍 Features
- 📰 **Feed Layout:** Clean and structured post feed design.
- 📸 **Stories Section:** Horizontally scrollable story highlights.
- 🧭 **Navigation Sidebar:** Icon-based navigation for easy access.
- 📱 **Responsive Design:** Optimized for different screen sizes.

---

## 🛠️ Technologies Used
- **HTML** for structure  
- **CSS** for styling, layout, and responsiveness  

---

## ⚙️ How It Works
1. Loads a static social media UI layout on page open.
2. Uses Flexbox to structure feed, stories, and navigation components.
3. Applies CSS styling for consistent spacing, alignment, and responsiveness.
4. Mimics real-world social media UI patterns for frontend practice.
